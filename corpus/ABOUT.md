# About this copy of the corpus

This is the corpus from `mason517/observation-agent-assignment` (commit 0d52185).
Each email file has been renamed so it works on Windows: `1.` became `1.txt`.

- The content of every file is unchanged, byte for byte.
- The folder layout is unchanged (`farmer-d/logistics`, `giron-d/inbox`, and so on).
- `MANIFEST.csv` lists the original path, the new path, the size and a SHA-256 hash for all 3,240 files.
- `.gitattributes` stops Git from changing line endings, so quoted text still matches the originals exactly.

When citing a message, give the original path from `MANIFEST.csv` (for example `corpus/giron-d/inbox/20.`), because that is the name in the reviewer's copy.
